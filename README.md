# TF Post Card Studio

ফেসবুক পেজের জন্য ফটো কার্ড ও ক্যাপশন তৈরির অ্যাপ — **সাধারণ** ও **ইসলামিক (প্রশান্তির বার্তা)**।
ফোন ও কম্পিউটার দুটোতেই চলে, আর ফোনে অ্যাপের মতো **ইনস্টল** করা যায়।

---

## ১. GitHub-এ আপলোড (একবারই করতে হবে)

1. **github.com**-এ গিয়ে লগইন করুন (অ্যাকাউন্ট না থাকলে *Sign up* করে নিন)।
2. উপরে ডানে **＋** → **New repository**।
3. *Repository name*: `post-card` (বা আপনার পছন্দের নাম) → **Public** বেছে নিন → **Create repository**।
4. পরের পাতায় **uploading an existing file** লিংকে চাপুন।
5. এই ফোল্ডারের **সব ফাইল** একসাথে টেনে এনে ছেড়ে দিন (বা *choose your files* দিয়ে সব বেছে নিন):
   `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`, `README.md`
6. নিচে সবুজ **Commit changes** বাটনে চাপুন।

## ২. ওয়েবসাইট চালু করা (GitHub Pages)

1. রিপোজিটরির উপরে **Settings** → বাম পাশে **Pages**।
2. *Branch*-এর নিচে **None** লেখাটায় চাপুন → **main** বেছে নিন → পাশের ঘরে **/ (root)** → **Save**।
3. ১–৩ মিনিট অপেক্ষা করে পাতাটি রিফ্রেশ করুন। উপরে লিংক দেখাবে, যেমন:
   `https://আপনার-ইউজারনেম.github.io/post-card/`

## ৩. ফোনে ইনস্টল করা

**অ্যান্ড্রয়েড (Chrome):** লিংকটি Chrome-এ খুলুন → অ্যাপের উপরে **📲 ইনস্টল** বাটন বা নিচের ব্যানারে চাপুন।
বাটন না দেখালে: উপরে ডানে **⋮** → **Install app** (বা *Add to Home screen*) → **Install**।

**আইফোন (Safari):** লিংকটি Safari-তে খুলুন → **Share □↑** → **Add to Home Screen** → **Add**।

এরপর হোম স্ক্রিনের আইকনে চাপলেই অ্যাপ সরাসরি খুলবে। একবার খোলার পর দুর্বল ইন্টারনেট বা অফলাইনেও খুলবে
(তবে হাদিস/আয়াত আনা ও AI-এর জন্য ইন্টারনেট লাগবে)।

## ৪. পরে আপডেট দেওয়া

নতুন `index.html` পেলে: রিপোজিটরিতে **Add file → Upload files** → নতুন ফাইলটি দিন → **Commit changes**।
কয়েক মিনিট পর অ্যাপ খুললে উপরে **"নতুন ভার্সন প্রস্তুত — রিলোড"** দেখাবে, সেটায় চাপুন।

## ৫. নিরাপত্তা

- আপনার **Gemini API কী কোনো ফাইলে নেই** — শুধু আপনার ফোন/ব্রাউজারের ভেতরে থাকে। রিপোজিটরি পাবলিক হলেও কী কেউ দেখতে পাবে না।
- প্রতিটি ডিভাইসে (ফোন, কম্পিউটার) আলাদাভাবে ⚙️ সেটিংসে কী দিতে হবে।
- চাইলে Google Cloud Console → Credentials → আপনার API key → *Website restrictions*-এ শুধু
  `https://আপনার-ইউজারনেম.github.io/*` যোগ করে দিন, তাহলে কী অন্য কোনো সাইট থেকে কাজ করবে না।
- লেখা, ডিজাইন ও লাইব্রেরি প্রতিটি ডিভাইসে আলাদা থাকে। এক ডিভাইস থেকে অন্যটিতে নিতে ⚙️ সেটিংস → **💾 সবকিছু সেভ করুন** → অন্য ডিভাইসে **📂 ফিরিয়ে আনুন**।
